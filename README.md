# eSIM Market Backend

`esim-market-backend` contains the backend services for the **eSIM Market** project.

It is responsible for exposing the web APIs used by the UI and for running background jobs required by the platform.

## Main Responsibilities

- Web/API services
- Business logic
- Data access
- Background jobs and workers
- Integration with external services

## Related Repositories

- `esim-market` — integration and local orchestration
- `esim-market-ui` — React frontend application
